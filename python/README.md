# Mock API (Python)

A modern implementation of the mock API server using **Python 3.12+** and **FastAPI**.

> [!WARNING]
> This implementation is currently **Under Development**.

## Features (Planned)

- **FastAPI-powered REST and GraphQL mocking**: Leveraging Python's asynchronous capabilities for high-performance mocking.
- **File-driven scenario selection**: Use a custom header to select specific mock JSON files.
- **Response Orchestration**: Cycle through a sequence of mock responses.
- **Delay simulation**: Simulate network latency.

## Getting Started

### Prerequisites

- [Python 3.12+](https://www.python.org/)
- [uv](https://github.com/astral-sh/uv) (Recommended for dependency management)

### Running the Server

Using `uv`:
```bash
uv run main.py
```
